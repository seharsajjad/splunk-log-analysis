# Splunk Log Analysis — SPL Queries

 1. Search All Events
index=main

 2. Filter HTTP Error Events
index=main sourcetype=access_combined | where status>=400

 3. Identify Top Source IP Addresses
index=main sourcetype=access_combined
| rex field=_raw "^(?<client_ip>\d{1,3}(?:\.\d{1,3}){3})"
| stats count by client_ip
| sort - count

 4. Analyze HTTP Status Codes
index=main sourcetype=access_combined
| stats count by status
| sort - count

Note: These queries were used to practice searching and analyzing sample web server logs in Splunk Cloud. The sample data may contain duplicate events, so counts represent indexed events, not necessarily unique requests.
